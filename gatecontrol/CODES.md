# Gate Control - Unlock Codes Reference

This file contains all the unlock codes available in Gate Control and the themes they unlock.

## How to Use Codes

Type `CODE <ACCESS CODE>` in the terminal to unlock themes.

## Special/Cheat Codes

| Code | Effect | Notes |
|------|--------|-------|
| `PRETTYCOLOURS` | Unlocks all themes at once | Developer/debug code |
| `NOMORELORE` | Re-locks all secret themes | Removes secret themes from profile data |
| `ILOVELORE` | Unlocks all secret themes | Secret themes only (no default/holiday/unlockable) |
| `ILOVEVETASO` | Restores all systems to 100% health | Restores FUEL, SUPPLY, relays, facility systems, beacon, alignment, sync to maximum/optimal state |

## Using Unlocked Themes

After unlocking a theme with a code, activate it by typing:
```
THEME <theme-id>
```

For example:
- `THEME CHRISTMAS`
- `THEME HALLOWEEN`
- `THEME WORKERS`
- `THEME NOSTALGIA`
- `THEME TESTING`
- `THEME HACKER`
- `THEME GRID`
- `THEME SUNSET`
- `THEME HAZARD`
- `THEME VINTAGE`
- `THEME DEEPSPACE`

## Persistence

Unlocked themes are now saved in your game saves and will persist between sessions. When you export your save file, your unlocked themes will be included and restored when you load the save.
