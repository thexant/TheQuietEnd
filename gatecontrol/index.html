Quickstart
What this is
This panel simulates a gate control terminal. You review inbound/outbound traffic, keep systems stable, and log actions in the console.
Workflow
  1. Check Alerts and Systems for instability.
  2. Review inbound/outbound queues for risky requests.
  3. Approve, Hold, or Deny ships as needed.
  4. Run maintenance when alignment or sync drifts.
Navigation and UI
Display
Switches the palette (Green/Red/Blue/Amber/Black). It does not affect the simulation.
Share / Export / Resume
SHARE copies a URL snapshot. EXPORT downloads a .tqegate save named after the active gate. RESUME loads a .tqegate file to restore a session.
Audio toggles
SFX and MUSIC toggle sound effects and background audio for this terminal.
Hard reset
RESET (top right) reboots the node, clears logs, starts a new shift, and assigns a fresh gate ID.
Top stats
Shift Time tracks how long the session has been running. Wage shows credits earned this shift. Alerts counts active issues.
Quick keys
Enter submits a command. ArrowUp recalls the last command. Esc clears the input. Esc also dismisses this panel.
Traffic Control
Traffic queue
Inbound and outbound tables show ships waiting to pass. Each row has actions: Approve (allow), Hold (delay for review), Deny (reject).
Ship detail
DETAIL <ID> reveals state, ETA, dock slot, transponder, priority flag, effects, and notes. NOTE <ID> <TEXT> saves operator notes.
Decon
DECON START <ID> begins decontamination. Ships that dock will usually require DECON. If you do not within 1-3 minutes, exposure may occur.
Manual actions
APPROVE <ID> / HOLD <ID> / DENY <ID> mirror the row buttons when you want to stay in the console.
Systems and Maintenance
Systems panel
Shows gate health, beacon state, alignment, sync, corridors, and facility status. Degraded or offline systems can trigger alerts and slow traffic.
Sync state
Sync can slip to ASYNC or FAULT during drift, relay instability, or failed restores. Maintenance Reset and healthy relays help return to SYNC.
Maintenance
Realign improves alignment, Reset reestablishes handshake and can recover the beacon, Purge clears low-priority queue entries, Scan looks for anomalies and reveals hidden effects.
Resources
Fuel drains over time. Supplies drain during work orders and decon. Orders can be placed any time, and the amount sets both cost and shipment size.
Console Commands
Status views
STATUS shows node health. LINKS lists corridor links. LIST INBOUND/OUTBOUND prints quick ship lists. RELAYS shows repeater status and ACK timers.
Diagnostics
PING <RELAY-ID> checks a relay. ACK <RELAY-ID> clears pending acknowledgments before they expire. RESTORE <RELAY-ID> can recover a FAULT or WEAK relay but may backfire.
Work orders
WORKORDER <SYSTEM> queues repairs on offline facility systems and consumes supplies until the work order resolves.
Packets + orders
PACKETS shows recent transmission chatter. ORDER <AMOUNT> FUEL or ORDER <AMOUNT> SUPPLY queues resupply for the requested amount.
Audio
SFX ON|OFF|TOGGLE and MUSIC ON|OFF|TOGGLE control sound effects and background music.
Theme + help
THEME GREEN|RED|BLUE|AMBER|BLACK swaps the display. HELP or ? lists all commands.
Logs and Cleanup
Event log
Right-hand log shows automated activity and system changes. Use it to spot problems without opening each row.
Clear logs
CLEAR wipes the console output. CLEAR EVENTS wipes the event log.
